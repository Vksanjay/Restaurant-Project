# Restaurant Menu Management System

A full-stack restaurant menu management application that allows users to manage restaurant menu items through a simple and responsive web interface.

## Features

- Add new menu items
- View menu items
- Update existing menu items
- Delete menu items
- Display food images, ratings, prices, and descriptions
- Responsive user interface
- REST API integration
- MongoDB database integration

## Technologies Used

### Frontend
- React.js
- JavaScript
- Bootstrap
- CSS
- Vite

### Backend
- Node.js
- Express.js
- Mongoose

### Database
- MongoDB

### Deployment
- Vercel

## CRUD Operations

The application implements the following CRUD operations:

- **Create** – Add new menu items
- **Read** – View menu items
- **Update** – Edit existing menu items
- **Delete** – Remove menu items
